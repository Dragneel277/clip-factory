Clip Factory

Clip Factory is a private tool used by its owner to schedule and upload videos to the owner's own YouTube channels (for example GTA Moments Daily and The Mindset Cut). It is not offered to the public and has no other users.

It uses the YouTube Data API only to upload videos, set their titles, descriptions, thumbnails and playlists, and read basic statistics of the owner's own channels.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

How to revoke access

You can remove this app's access to your Google account at any time at myaccount.google.com/permissions (select "Clip Factory" and choose "Remove access").
